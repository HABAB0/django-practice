#  Local Library (Django Practice)

**Local Library** — это полнофункциональное веб-приложение для каталогизации и управления библиотечным фондом, разработанное на фреймворке Django. Проект демонстрирует навыки бэкенд-разработки: работу с ORM, создание представлений (Views), шаблонизацию, маршрутизацию и систему аутентификации пользователей.


---

##  Основные возможности

- **Каталогизация:** Просмотр списков книг, авторов и жанров с детальной информацией о каждом экземпляре.
- **Система аутентификации:** Регистрация, вход, выход пользователей и ограничение доступа к определенным страницам.
- **Личный кабинет:** Отображение истории взятых книг и текущих активных бронирований для авторизованных пользователей.
- **Административная панель:** Полноценный интерфейс Django Admin для удобного управления контентом (CRUD-операции).
- **Работа с базой данных:** Использование Django ORM для сложных запросов, пагинации и оптимизации выборки данных.

##  Структура проекта

Проект использует классическую и понятную структуру Django:

```text
├── locallibrary/      # Настройки и конфигурация проекта (settings.py, urls.py, wsgi.py)
├── catalog/           # Основное приложение (модели, представления, формы, URL-маршруты)
├── templates/         # HTML-шаблоны для рендеринга страниц (включая папку registration)
├── static/            # Статические файлы (CSS, изображения, JS)
├── .gitignore         # Исключаемые файлы и директории
├── manage.py          # Утилита командной строки для взаимодействия с Django
└── README.md          # Документация проекта
```

##  Установка и локальный запуск

Для запуска проекта на вашем локальном компьютере выполните следующие шаги:

### 1. Клонирование репозитория
```bash
git clone https://github.com/HABAB0/django-practice.git
cd django-practice
```

### 2. Создание и активация виртуального окружения
```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install django
# Если в проекте есть файл requirements.txt, используйте:
# pip install -r requirements.txt
```

### 4. Применение миграций
Создаст структуру базы данных на основе моделей Django:
```bash
python manage.py migrate
```

### 5. Создание суперпользователя (для доступа к админ-панели)
```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```
После запуска основное приложение будет доступно по адресу: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**  
Административная панель: **[http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)**

##  Как пользоваться

1. **Главная страница:** Отображает общую статистику библиотеки (количество книг, доступных экземпляров, авторов).
2. **Каталог:** Перейдите в раздел "Books" или "Authors", чтобы просмотреть доступные записи.
3. **Детальная страница книги:** Показывает информацию о книге, ее жанре, авторе и списке конкретных экземпляров с их статусом (доступен / взят).
4. **Авторизация:** Нажмите "Login" в верхнем меню, чтобы войти в систему. После входа станет доступен раздел "My Borrowed" (Мои книги).
5. **Админ-панель:** Используйте учетные данные суперпользователя для входа в `/admin` и управления записями через удобный GUI.
